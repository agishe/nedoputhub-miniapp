# Недопутешественники — Mini App

Веб-интерфейс (Telegram Mini App) для отправки постов в канал «Недопутешественники», модерации заявок, управления отложкой и просмотра статистики.

Работает внутри Telegram через `telegram-web-app.js`.

---

## 📁 Структура репозитория

| Файл | Роль |
|---|---|
| `index.html` | Разметка Mini App: вкладки «Предложить», «Модерация», «Отложка», «Статистика», «Помощь»; форма отправки; блок прогресса с машинкой |
| `style.css` | Стили: тема Telegram (светлая/тёмная), чипы, карточки, прогресс-бар с параллаксом (газон, облака, машинка) |
| `app.js` | Логика: авторизация через `initData`, каталоги, отправка постов, загрузка медиа, модерация, отложка, статистика, FAQ, анимация прогресса |

Никаких сборщиков, npm, node_modules — чистый HTML/CSS/JS.

---

## ✨ Возможности

### Для подписчиков
- 📸 **Отправка постов** — текст + до 20 файлов (фото/видео), до 32 768 символов.
- 🏷 **Рубрики** — 14 штук (горы, море, страны, города и т.д.).
- 🌍 **Гео** — 9 стран кнопками + ручной ввод стран/городов.
- 🕵️ **Анонимность** — с автором или анонимно.
- 📖 **FAQ** — аккордеон с частыми вопросами.

### Для админов (вкладки видны только при `is_admin`)
- 📝 **Модерация** — заявки с кнопками «Опубликовать», «Отложить», «Отклонить», «Удалить», «Скрыть/Показать автора».
- ⏰ **Отложка** — список запланированных постов, редактирование текста, удаление.
- 📊 **Статистика** — за сегодня / 7 / 30 дней: всего, авто, вручную, отклонено, отложено, топ рубрик, топ авторов, подписчиков.

### UX-фишки
- 🚗 **Прогресс с машинкой** — при отправке поста появляется анимированная сцена: машинка едет по дороге, сверху облака/солнце, снизу домики/деревья (все объекты случайные, с параллаксом).
- 🔒 **Валидация на фронте** — не даст ввести текст длиннее 32 768, добавить файл > 50 МБ или больше 20 файлов.
- 🎨 **Авто-тема** — светлая/тёмная через `--tg-theme-*` переменные Telegram.

## 📏 Лимиты

| Параметр | Mini App | Бот (личные сообщения) |
|---|---|---|
| Текст | **32 768** символов | 4096 (без медиа) / 1024 (с медиа) |
| Файлы | **20** | 10 |
| Размер файла | **50 МБ** | 50 МБ |

## ⚙️ Требования

- Telegram WebApp SDK (`telegram.org/js/telegram-web-app.js`) — подключён в `index.html` из CDN, ничего ставить не нужно.
- Современный браузер (Telegram WebView на iOS/Android/Desktop).
- Никаких зависимостей, сборки, npm.

---

## 🎨 Структура `app.js` (кратко)

- **`state`** — текущее состояние (user, mode, categories, countries, catalogs, statsDays).
- **`FAQ_DATA`** — массив вопрос-ответ для вкладки «Помощь».
- **Прогресс с машинкой** — `showProgress()`, `updateProgressLabel()`, `finishProgress()`, `hideProgress()`, `populateDriveScene()`.
- **Утилиты** — `$`, `show`, `hide`, `esc`, `tgConfirm`, `setBtnLoading`, `api`, `uploadFile`, `uploadMedia`.
- **Жизненный цикл** — `boot()` (старт), `renderUserBar()`, `renderCatalogs()`, `renderFAQ()`.
- **Форма** — `bindSubmitForm()`, `updateCharCounter()`, `updateDynamicHint()`, `clearForm()`.
- **Модерация** — `loadModeration()`, `modAction()`.
- **Отложка** — `loadSchedule()`, `schedAction()`.
- **Статистика** — `loadStats()`.

## 🐛 Известные ограничения

- `window.confirm` / `window.alert` в Telegram WebApp не работают — используются `tg.showConfirm` / `tg.showAlert` (см. `tgConfirm()`).
- Rich Messages (32 768 символов) отправляются **только через Mini App**. Через бота (личные сообщения) лимит остаётся 4096/1024.
- Редактирование медиа после отправки невозможно — только текст.
- Прогресс-бар — чисто визуальный, реальный прогресс загрузки не показывается (fetch не поддерживает upload progress в Telegram WebView).
